# 星趴四人单局评分 v0.2

输入一个 **16 位回放号**，自动下载并解析回放，输出四名玩家的 **v0.2 单局表现评分和同条件百分位**。

适用于 **地图 `82017`（森秋幻境）、难度 `3`（疯狂）**，包含 36 个角色量表。其他地图或难度会提示不适用。

> 百分位表示本局表现相对于同角色、同地图、同难度冻结参考样本的位置，不是玩家稳定实力、胜率或游戏官方评分。

## 运行环境

- Python 3.10+
- 运行评分时需要联网下载指定回放
- 不需要机器人、游戏账号或登录态

## 安装与使用

在项目根目录执行：

```bash
python -m pip install -r requirements.txt
python score.py 1234567890123456
```

把 `1234567890123456` 换成实际的 16 位回放号。输出形式为：

```text
回放 回放号｜36角色单局量表 v0.2
玩家昵称（角色）：本局评分 分数｜同条件百分位 百分位%
……共四名玩家……
百分位按同角色、同地图、同难度冻结样本计算，不代表长期实力或胜率。
```

也可以在 Python 中调用：

```python
from rate_core import rate_replay

text = rate_replay("1234567890123456")
print(text)
```

## 评分流程

1. 从国服回放 CDN 下载指定回放。
2. 使用内置的 AstralParty_Dex 模块解析四名玩家及逐回合数据。
3. 整理伤害、转账、治疗、移动、承伤和死亡等评分字段。
4. 将各指标转换为同角色冻结参考分布上的中点秩百分位。
5. 按角色 JSON 中的 v0.2 权重计算 `raw_score`。
6. 对冻结原始分参考分布再次排序，得到 `overall_percentile`。

量表只读，不会在运行时训练或修改参考分布。
